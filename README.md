# The Art of Becoming

A responsive React website about creativity, curiosity, exploration, and growth. Includes an interactive mandala coloring studio.

## Run locally
Requirements: Node.js LTS. Open this folder in VS Code, choose Terminal → New Terminal, then run:

```bash
npm install
npm run dev
```

Open the local URL printed in the terminal, usually http://localhost:5173.

If PowerShell blocks `npm.ps1` on Windows, switch the VS Code terminal profile to **Command Prompt** and rerun the commands.

## Build
```bash
npm run build
```

## Personalize
- Edit copy in `src/App.jsx`.
- Change colors/layout in `src/index.css`.
- Add artwork to `public/images/`.
- Update the learning/project descriptions so they accurately reflect your experience.
